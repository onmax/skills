# Grill With Docs

Run a decision interview, one question at a time. The goal is a closed decision frontier, not a long conversation.

Read [INTERVIEW.md](INTERVIEW.md) for the frontier and decision-tree loop. Start from the existing proposal, code, notes, or conversation. Ask the highest-leverage unresolved question, challenge contradictions with concrete evidence, record the answer, and continue until the remaining uncertainty no longer changes the next action.

Do not create documentation merely because the skill name contains “docs.” Write or update a durable artifact only when the user explicitly asks for one. When they do, agree on the target path and artifact type, then keep the document synchronized with each settled decision rather than reconstructing it from memory at the end.

Finish with the decision, rejected alternatives that matter, unresolved risks, and the next action. If an artifact was requested, include its exact path.
